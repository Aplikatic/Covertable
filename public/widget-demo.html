Comida deliciosa, lista en minutos

Esta es una página simulada que demuestra cómo se vería la web de un cliente con el widget Covertable embebido. Pulsa el botón flotante para abrir el flujo de pedido sin salir de esta página.

Cómo funciona

Esta página incluye una sola etiqueta <script> apuntando a /widget.js de la instalación Covertable. El script inyecta un botón flotante y, al pulsarlo, abre un iframe modal con el flujo de pedido completo.

En producción el cliente final pegaría exactamente el mismo snippet en su propia web (WordPress, Wix, HTML estático, etc.). El widget se sirve desde la URL del tenant de Covertable.
